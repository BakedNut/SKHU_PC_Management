# UI Structure Spec

## UI 목표

SKHU PC Management UI는 Windows 11 스타일의 관리 앱을 목표로 한다. 사용자는 `PC 정보`, `작업 센터`, `네트워크` 세 화면을 왼쪽 내비게이션으로 전환한다.

원칙:

- 사용자-facing 문구는 한국어.
- 제품키는 화면에 표시하지 않음.
- 위험 작업은 버튼 role, 확인 대화상자, 테스트 모드 비활성화로 구분.
- UI는 ViewModel/use case를 호출하고 Windows 세부 구현을 직접 수행하지 않음.

## 전체 레이아웃

| 요소 | 구현 |
| --- | --- |
| 상단 헤더 | 앱 제목, subtitle, Windows version badge, PC name badge, test mode 표시 |
| 왼쪽 내비게이션 | `PC 정보`, `작업 센터`, `네트워크` |
| 콘텐츠 | `QStackedWidget` 기반 3개 panel |
| busy banner | 장시간 작업 중 중복 실행 방지와 상태 표시 |
| test mode banner | `테스트 모드에서는 실제 설정 변경 기능이 비활성화됩니다.` |

QTabWidget 구조가 아니다.

## 공통 컴포넌트

| 컴포넌트 | 역할 |
| --- | --- |
| `Card` | 주요 카드 컨테이너 |
| `SectionCard` | 카드 내부 섹션 |
| `SummaryCard` | 요약 값 카드 |
| `StatusBadge` | 상태 pill |
| `primary_button` | 주요 실행 버튼 |
| `secondary_button` | 보조 실행 버튼 |
| `subtle_button` | 낮은 강조 버튼 |
| `warning_button` | 주의 작업 |
| `danger_button` | 삭제/초기화 |
| `configure_table` | 공통 table 스타일 |

## 버튼 역할

| role | 사용 예 |
| --- | --- |
| `primary` | 선택한 설정 적용, IP 설정 적용, 인증 준비, 전원 옵션 적용, 23시 자동종료 적용 |
| `secondary` | 일반 보조 작업 |
| `subtle` | 전체 선택/해제, 기본 대역 입력 |
| `warning` | 현재는 제한적으로 사용 |
| `danger` | Chrome/Edge 사용자 데이터 초기화 |
| `nav` | 왼쪽 화면 이동 |

PC 정보의 `PC 이름 변경`은 `pcActionPrimaryButton` objectName을 사용하며, 연한 파란 배경/파란 테두리/파란 텍스트의 전체폭 큰 버튼이다.

## PC 정보 화면

| 영역 | 내용 |
| --- | --- |
| 요약 | PC 이름 등 핵심 정보 |
| 시스템 정보 | PC 이름, 사용자, Windows 버전 |
| 하드웨어 정보 | CPU, RAM, GPU |
| 디스크 table | 모델, 유형, 정격/실제 용량 |
| PC 작업 | `PC 이름 변경` 버튼 하나 |
| 보안/호환 상태 | TPM, Secure Boot, Boot Mode |

`PC 이름 변경`은 Windows 설정 시스템 정보 화면을 열며 앱 내부 rename dialog를 표시하지 않는다. 테스트 모드에서는 버튼을 비활성화한다.

앱 시작 시 자동 조회는 PC 기본 정보로 제한한다. PC 이름 변경 화면 열기는 Windows 설정 앱 실행만 수행하고 PC 정보 전체 refresh를 자동 실행하지 않는다.

## 작업 센터 화면

| 영역 | 내용 |
| --- | --- |
| summary row | `설정 상태`, `PC 점검`, `강의실 정책` |
| 권장 조치 | 설정/점검/강의실 정책 상태 기반 안내 |
| 인증 | Windows 11/10, Office 2024/2021 선택과 실행 버튼 |
| 시스템 설정 선택 | OS 선택, checkbox list, 전체 선택/해제, 선택한 설정 적용 |
| 즉시 실행 도구 | 휴지통, Chrome/Edge User Data 초기화, 프로그램 실행 |
| 시스템 설정 적용 상태 | 3열 table: `설정 항목`, `현재 상태`, `상세` |
| PC 점검 결과 | 3열 table: `항목`, `상태`, `상세 내용` |
| 강의실 PC 전용 작업 | 전원 옵션 `안 함`, 23시 자동종료 |

중요 UI 정책:

- 앱 시작 시 설정 상태 확인과 PC 점검은 자동 실행하지 않는다.
- 작업 센터 탭 첫 진입 시 설정 상태 확인과 PC 점검을 자동으로 1회 실행한다.
- 이후 작업 센터 탭 재진입 시 자동 재조회는 반복하지 않고, 사용자가 `상태 새로고침`을 누르면 다시 실행한다.
- Office summary card는 상단 summary row에 없다.
- Office 설치 상태는 인증 카드 Office row에만 표시한다.
- PC 점검 table에는 `Office 설치 확인` 행을 표시하지 않는다.
- Windows 10 선택 시 Win11 전용 시작 메뉴 checkbox row와 상태 row를 제외한다.
- 설정 상태 table에는 적용 로그를 섞지 않는다.
- Chrome/Edge/PotPlayer/Bandizip 실행 버튼은 외부 프로그램 실행만 수행하고 설정 상태 확인/PC 점검 전체 재조회를 호출하지 않는다.

## 인증 카드

- 상단 안내: 제품키는 화면에 표시하지 않으며 버튼 실행 시에만 복사됨.
- Windows row: Windows 11/10 radio, 현재 감지, `복사 및 인증 창 열기`.
- Office row: Office 2024/2021 radio, 현재 감지, `복사 및 Excel 실행`.
- 우측에는 별도 `선택: Windows ...` 텍스트를 표시하지 않는다.

## 시스템 설정 섹션

- `기본 환경`, `탐색기/작업 표시줄`, `시작 메뉴` 3개 섹션 구조.
- 각 섹션 wrapper는 `settingsSection` 스타일로 테두리 있는 카드 형태.
- Windows 10 선택 시 시작 메뉴 섹션은 disabled 상태이며 Win11 전용 항목을 숨기거나 비활성화한다.
- `Win11 전용` badge는 disabled section 안에서도 읽기 쉬운 info tone을 유지한다.

최신 설정 항목:

| 섹션 | 항목 |
| --- | --- |
| 기본 환경 | 기본 배경화면 설정, 바탕화면 `내 PC` 아이콘 표시, 바탕화면 `제어판` 아이콘 표시, 바탕화면 Edge 바로가기 삭제, 작업표시줄 아이콘 설정, 부팅 시 암호 입력 생략 설정 활성화, 빠른 시작 켜기 비활성화, 사용자 계정 암호 만료 비활성화 |
| 탐색기/작업 표시줄 | 자주 사용하는 폴더 숨김, 최근 사용한 항목 숨김, 탐색기 실행 시 `내 PC`로, 파일 선택 확인란 비활성화, 파일 확장자 표시, 작업 보기 버튼 숨김, 검색 아이콘만 표시 |
| 시작 메뉴 | 시작 메뉴: 고정된 항목 더 보기, 시작 메뉴: 최근 추가 앱 숨김, 시작 메뉴: 자주 사용 앱 숨김, 시작 메뉴: 추천 파일 숨김, 시작 메뉴: 팁/권장 사항 숨김, 시작 메뉴: 계정 알림 숨김 |

## 네트워크 화면

| 영역 | 내용 |
| --- | --- |
| IP 구성 | adapter combo, IP/subnet/gateway/DNS 입력 |
| 현재 네트워크 상태 | 현재 adapter, IP 할당 방식, IP, subnet, gateway, DNS table |

네트워크 상단 summary card(`현재 어댑터`, `IP 할당 방식`, `IP 주소`)는 없다. 중복 정보는 현재 상태 table에서만 표시한다.

앱 시작 시 네트워크 어댑터 조회를 자동 실행하지 않는다. 네트워크 탭 첫 진입 시 어댑터 목록과 현재 상태 table을 자동으로 1회 불러온다. 이후 같은 탭 재진입 시 자동 재조회는 반복하지 않고, 사용자가 `어댑터 새로고침`을 누르면 다시 실행한다.

성공적인 어댑터 로드 메시지는 별도 status label에 계속 노출하지 않는다. 오류와 validation 메시지만 표시한다.

## 상태 표시 규칙

| 문자열 | tone |
| --- | --- |
| 정상, 설정됨, 적용됨, 최신 | success |
| 주의, 미설정, 값 없음, 설치되지 | warning |
| 확인 중, 진행 중 | info |
| 확인 불가, 알 수 없음, 미구현 | neutral |
| 실패, 오류 | danger |

긴 detail은 table cell tooltip에도 넣는다.

## 테스트 모드 UI

테스트 모드에서는 다음 버튼을 비활성화하고 tooltip/status에 공통 메시지를 표시한다.

- PC 이름 변경.
- 선택한 설정 적용.
- 인증 준비.
- Chrome/Edge 사용자 데이터 초기화.
- 프로그램 실행.
- 전원 옵션/자동종료 적용.
- 정적 IP/DHCP 적용.

읽기 전용 조회 버튼은 유지한다.

## 팝업 정책

단순 실행 버튼은 성공 시 완료 팝업을 표시하지 않는다. 사용자는 외부 프로그램 또는 Windows 설정 창이 열리는 것으로 성공을 확인한다. 실패, 미구성, 테스트 모드 차단은 팝업으로 알릴 수 있다.

단순 실행 버튼은 실행 후 전체 설정 상태 확인이나 PC 점검을 자동으로 다시 실행하지 않는다.

성공 팝업을 생략하는 단순 실행 버튼:

- Chrome 실행.
- Edge 실행.
- 팟플레이어 실행.
- 반디집 실행.
- PC 이름 변경.

확인 대화상자를 유지하는 작업:

- Chrome/Edge User Data 초기화.
- 휴지통 비우기.
- 전원 옵션 `안 함` 적용.
- 23시 자동종료 적용.
- 고정 IP 적용/DHCP 전환.

## 확인 대화상자

| 작업 | 확인 |
| --- | --- |
| Chrome/Edge User Data 초기화 | User Data 전체 삭제 위험 고지 |
| 휴지통 비우기 | 휴지통 항목 삭제 확인 |
| 전원 옵션 `안 함` 적용 | 전원 정책 변경 확인 |
| 23시 자동종료 적용 | 예약 작업 등록 확인 |
| 고정 IP 적용/DHCP 전환 | 네트워크 변경 확인 |

인증 준비는 제품키를 표시하지 않고 결과 메시지도 키 값을 포함하지 않는다.

## QMessageBox 스타일

앱 내부 `QMessageBox`는 Windows 다크 테마에서도 본문과 버튼 텍스트가 읽히도록 라이트 테마로 고정한다.

- 팝업 배경: 흰색.
- 본문 텍스트: 어두운 회색.
- 버튼: 파란색 배경, 흰색 텍스트.
- hover/pressed/disabled 상태 정의.

이 정책은 Qt `QMessageBox`에 한정하며 Windows 네이티브 파일 선택 대화상자 같은 시스템 다이얼로그까지 스타일링하지 않는다.
